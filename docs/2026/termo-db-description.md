# База данных свойств термодинамических компонентов

Для расчета свойств смеси необходимо знать термодинамические параметры отдельных компонентов, а также константы, характеризующие взаимодействие компонентов между собой (бинарные коэффициенты взаимодействия — Binary Interaction Parameter — BIP). BIP можно взять из табличной БД либо оценить по корреляционным моделям на основе параметров отдельных компонентов.

Абстракция смеси компонентов (флюид) формируется с помощью БД на основе:
1. Списка формул или CAS-номеров компонентов
2. Мольных долей (опционально)
3. Матрицы BIP: либо явной, либо через план оценки BIP

План оценки BIP представляет собой набор правил - для пары компонентов (заданных CAS-номером) указывается способ определения коэффициента взаимодействия — взять значение из БД, рассчитать по корреляции, задать фиксированным значением.

При формировании флюида если задан непустой план, на его основе формируется матрица BIP — числа в матрице определяются по правилам плана. Если план не задан и явная матрица не передана, матрица BIP пустая. В расчётах PR EOS все коэффициенты взаимодействия считаются нулевыми.

БД предоставляет интерфейс со следующим инвариантом: если по названию метода не указан способ задания компонента — формула или CAS-номер — то поддерживаются оба варианта. CAS-номера уникальны (в отличие от формул — изомеры имеют одинаковую формулу, но являются разными веществами), поэтому если переданный компонент не найден среди присутствующих в БД CAS, то компонент считается заданным формулой.
